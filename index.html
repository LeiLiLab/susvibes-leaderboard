Is Vibe Coding Safe? Benchmarking Vulnerability of Agent-Generated Code in Real-World Tasks

SusVibes is a benchmark of 186 real-world, repository-level software engineering tasks that tests whether vibe-coding agents produce code that is not only functional but also secure. We evaluate frontier LLMs (Claude 4 Sonnet, Gemini 2.5 Pro, Gemini 3 Pro, Kimi K2) across agent frameworks (SWE-agent, OpenHands, Claude Code).
